# 🧠 Overview

**DAYFLOW AI** is an intelligent **Odoo 17 HR workforce intelligence platform** that extends traditional HR management with explainable workforce risk analysis, proactive HR alerts, department intelligence, smart leave impact analysis, attendance trend analysis, and an AI HR Copilot.

Traditional HRMS platforms mainly store and display HR information.

DAYFLOW AI goes further by analyzing workforce data and helping HR understand:

- What is happening?
- Why is it happening?
- Which employees or departments need attention?
- What action should HR consider next?

---

# 🎯 Problem

Traditional HR systems manage:

- Employee records
- Attendance
- Leave
- Payroll
- Reports

However, HR teams often need to manually analyze this information to identify:

- Increasing absenteeism
- Declining attendance
- Repeated late check-ins
- High-risk employees
- Low department availability
- Leave conflicts
- Workforce capacity issues

This creates a gap between **HR data** and **HR decision-making**.

# 🧠 Workforce Intelligence

## 🎯 1. Workforce Risk Engine

DAYFLOW AI calculates an explainable workforce risk score from **0–100**.

|  Score | Risk Level |
| -----: | ---------- |
|   0–39 | 🟢 LOW     |
|  40–69 | 🟡 MEDIUM  |
| 70–100 | 🔴 HIGH    |

Risk analysis considers:

* Attendance percentage
* Absence frequency
* Leave frequency
* Late check-ins
* Attendance trends
* Department availability
* Workforce capacity
* Leave overlap

### Example

```text
Risk Score: 82
Risk Level: HIGH

Reasons:
• Attendance below department average
• Increased absence frequency
• Repeated late check-ins
• Declining attendance trend

Recommendation:
Schedule an HR check-in and review workload.
```

> The workforce risk engine is an explainable, rule-based analysis system. It is not presented as scientifically validated predictive machine learning.

# 🏖️ 5. Smart Leave Impact Analyzer

Before approving a leave request, DAYFLOW AI analyzes its potential workforce impact.

It considers:

* Department size
* Existing approved leave
* New leave request
* Available employees
* Projected availability

Example:

```text
Current Availability: 80%
Projected Availability: 70%

Leave Impact: HIGH

Recommendation:
Review team coverage before approval.
```

### Important

DAYFLOW AI does **not** automatically reject leave.

The system provides decision support.

**HR/Admin makes the final decision.**

# 🚀 Installation

## Requirements

* Odoo 17
* PostgreSQL
* Python compatible with Odoo 17
* Odoo HR modules

## 1. Clone Repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd <YOUR_PROJECT_DIRECTORY>
```

## 2. Add Module

Place the `dayflow_ai` folder inside your Odoo custom addons directory.

```text
odoo/
└── custom_addons/
    └── dayflow_ai/
```

## 3. Configure Odoo

Add the custom addons directory to `addons_path`.

```ini
addons_path = addons,custom_addons
```

## 4. Start Odoo

```bash
python odoo-bin -c odoo.conf
```

## 5. Open Odoo

```text
http://localhost:8069
```

## 6. Install Dayflow AI

```text
Apps
→ Update Apps List
→ Search "Dayflow AI"
→ Install
```
